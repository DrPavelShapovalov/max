# reels-desk

Ролик описывается одним файлом `reel.json`, движок `engine/desk.html` рисует любой момент `t`,
`scripts/render.cjs` снимает кадры в Chromium и склеивает mp4 со звуком через ffmpeg.
Сеть не нужна: шрифты (PT Mono, Caveat, Rubik — OFL) и звуки (синтез ffmpeg) лежат здесь.

Папка ролика: `branding/dr-shapovalov/reels/<slug>/` → `reel.json` + картинки. Готовое — в `<slug>/out/` (в git не идёт).

## Четыре шага

1. **Сценарий.** 5–8 фраз по 2–4 секунды, 12–20 с всего. Каждая фраза = одна субтитр-плашка = один кадр/действие.
   Факты — только из материалов автора (сайт `branding/dr-shapovalov/site/content.json`, его статьи) или явно помечены как общие сведения.
   Голос автора — `.claude/instagram/voice.template.md`, если заполнен. Перед показом прогони текст через `/ig-human`.
2. **Стиль.** Раскладка стола: лист-конспект (`paper`) с теми же фразами, что в субтитрах, заголовок-стикер (`note`),
   фото/схема (`photo`), папка с ярлыком (`folder`), рукописная надпись (`scrawl`). Тема по умолчанию: стол `#d6d0c6`,
   бумага `#f5f2ea`, маркер `#e2512b`, крафт `#b58a58`.
3. **Сборка.** Напиши `reel.json` (схема ниже), затем:
   ```bash
   S=.claude/skills/reels-desk/scripts/render.cjs; R=branding/dr-shapovalov/reels/<slug>
   node $S $R --lint      # обязательно: запретные зоны и «одна вещь в движении»
   node $S $R --sheet     # контактный лист out/sheet.jpg (кадр каждые 1,5 с, розовым — запретные зоны) — посмотри его
   node $S $R --still 7.2 --guides   # один кадр, если нужно проверить деталь
   node $S $R --name <slug>          # итоговый out/<slug>.mp4 (~70 с на 17 с ролика)
   ```
   Отправь mp4 пользователю (`SendUserFile`, display: render).
4. **Правки.** Меняй только `reel.json` и пересобирай; после каждой правки — снова `--lint`.

## Правила кадра (проверяет `--lint`)

- **Камера: одна вещь в движении за раз.** Пока едет камера — предметы лежат, маркер не рисует; предмет падает на стол, когда камера стоит.
- **Маркер звучит там, где рисуется** — звук создаётся автоматически из каждой пометки, ничего отдельно не прописывай.
- **Верх 220 px и низ 420 px — без читаемого текста** (там интерфейс Instagram). Субтитры сами встают над нижней зоной.
  Мелкий нечитаемый текст на общем плане (строка ниже 24 px) и текст в момент проезда камеры не считаются.
  Справа ~140 px тоже занимают кнопки Instagram — ключевой текст держи левее.
- Крупный план листа: зум ~1,15, камера по `y` = центр текстового блока + (960 − 700) / зум, чтобы текст встал в верхнюю половину, а под ним осталось место субтитрам.
- Обводка — на одну строку/деталь за кадр; 3–6 пометок на ролик. Подчёркивание — для вопроса, кольцо — для ответа, галочка — для пункта списка.
- Пациенты: только схемы, рисунки, свои фото автора. Фото пациентов — лишь с письменным согласием, глаза закрыты, имена размыты (правила `case-collage`). На схеме подпиши «схема, а не снимок пациента».

## reel.json

```jsonc
{
  "fps": 30, "duration": 17, "w": 1080, "h": 1920,
  "theme": { "desk": "#d6d0c6", "paper": "#f5f2ea", "ink": "#2b2724", "marker": "#e2512b", "kraft": "#b58a58" },
  "items": [                       // координаты мира в px, x/y — центр предмета, rot — градусы, z — слой
    { "id": "title", "type": "note", "x": 1450, "y": 950, "w": 940, "h": 210, "rot": -3, "fs": 56,
      "text": "КАК РАСТЁТ *кость*", "in": { "t": 0.3, "from": "top", "dur": 0.55 } },   // *слово* — крупно цветом маркера
    { "id": "proto", "type": "paper", "x": 1400, "y": 1800, "w": 1000, "h": 950, "rot": 2, "fs": 40,
      "file": "дистракция.txt", "lines": ["Строка", "", "**жирный**, ==заливка маркером==, *цвет маркера*"] },
    { "id": "jaw", "type": "photo", "x": 2650, "y": 1700, "w": 1100, "h": 900, "src": "jaw.png",
      "caption": "подпись от руки", "pos": "50% 25%", "in": { "t": 6.4, "from": "right" } },
    { "id": "folder", "type": "folder", "x": 2750, "y": 3560, "w": 900, "h": 1050, "rot": 7, "label": "детская ЧЛХ" },
    { "id": "note2", "type": "scrawl", "x": 900, "y": 2500, "w": 600, "h": 100, "text": "≈ 1 мм/сутки", "fs": 80 }
  ],
  // [t начала, x, y, зум, поворот, "io"|"out"|"sine"|"lin", длительность мс] — камера стоит между ключами
  "camera": [[0, 1450, 1640, 0.62, 0, "io", 0], [1.0, 1400, 1955, 1.15, -2, "io", 900]],
  // ring | underline | check | strike — по строке листа ("line": индекс) или по прямоугольнику "at": [x,y,w,h] в координатах предмета;
  // arrow — "from": [x,y], "to": [x,y], "bend"
  "marks": [{ "t": 2.8, "dur": 0.6, "type": "ring", "target": "proto", "line": 1 }],
  "captions": [{ "t": 0.4, "end": 1.9, "text": "Челюсть у ребёнка *недоразвита*?" }],   // неразрывный пробел — между «≈ 1 мм»
  "audio": { "voice": "voice.m4a", "voiceAt": 0, "voiceGain": 1, "music": "bed.mp3", "musicGain": 0.15 },  // необязательно
  "whoosh": true                    // мягкий шорох на переездах камеры
}
```

Ритм, который работает: камера едет 0,9 с → пауза 0,1 с → маркер 0,5–0,6 с → держим кадр, пока читается субтитр.
Субтитр меняется одновременно с началом движения, а не посреди него.

## Голос

Если автор прислал озвучку — положи файл в папку ролика, впиши `audio.voice` и подгони `t`/`end` субтитров и пометок под реплики
(длительность: `ffprobe -show_entries format=duration voice.m4a`). Без голоса ролик держится на субтитрах и звуках маркера.

Пример целиком: `branding/dr-shapovalov/reels/kak-rastet-kost/`.
