# Кейсы «до / после» для @dr__shapovalov

Утверждённый стиль и код: `branding/dr-shapovalov/collage/` (README.md — дизайн и
кадрирование, POSTS.md — правила текстов, case.example.json — пример кейса).
Не менять дизайн без запроса доктора — он его утвердил.

## Коллажи

1. Разложи присланные фото по ракурсам: лицо (анфас, правый профиль, левый профиль),
   прикус (фронтально, сбоку). Работай в `branding/dr-shapovalov/collage/cases/<кейс>/`
   или во временной папке — **фото пациентов никогда не коммитить и не публиковать
   в Artifact/внешние сервисы.**
2. Для каждого фото измерь в пикселях (нарезай участки с координатной сеткой и смотри):
   - `eyes` — круги поверх глаз `[cx, cy, r]`, r ≈ 0,6 ширины глаза; дальний глаз на
     профиле тоже, если виден;
   - `anchor`, `ref`, `include` — по таблице «Масштаб и кадрирование» в README.
     Измеряй `ref` на увеличенных фрагментах: ошибка здесь сразу видна как разный
     размер зубов/лиц в паре.
3. Заполни `case.json` по образцу `case.example.json` (для новых кейсов — `"zoom": "out"`, для прикуса с разной съёмкой — раскладка `justified`) и запусти
   `python3 branding/dr-shapovalov/collage/render.py <путь>/case.json`.
4. Посмотри результат. Проверь каждый край каждой ячейки: нос, подбородок, губы и весь
   зубной ряд целиком и с запасом — доктор жёстко реагирует на обрезанную анатомию.
   Глаза закрыты только на фото лица (на КТ и прикусе — нет), пары одного масштаба.
5. Отдай файлы доктору через SendUserFile.

## Тексты

Следуй POSTS.md. Факты о пациенте — только от доктора; общие научные утверждения —
только с источником (дай ссылки доктору в ответе). Instagram ≤ 2200 символов с
хэштегами; Telegram — без хэштегов, `**жирный**` / `__курсив__`, текст в блоке кода,
публикация «альбом + текст отдельным сообщением».

## Общение

Доктор пишет по-русски, коротко. Отвечать по-русски, без выдумок: если что-то не
проверено — так и сказать.
