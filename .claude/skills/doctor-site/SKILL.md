# Сайт врача: как делать и не нарваться на штраф

Навык собран по работе над drshapovalov.ru (детский челюстно-лицевой хирург, ноябрь 2026).
Рабочий код этого сайта: `branding/dr-shapovalov/site/` (см. его README) — бери оттуда, а не пиши заново.

## Порядок работы

1. **Факты — только от врача.** Регалии, цифры, отзывы, кейсы, цены — только из его слов или документов.
   Общие медицинские утверждения — только с источником, который даёшь врачу. Не выдумывай отзывы и статистику.
2. **Структура и тексты** → `references/structure.md`.
3. **Дизайн** → `references/design.md` (дизайн-скиллы: `taste-skill`, `impeccable`, `awesome-design-md`, `hallmark`).
4. **Архитектура и безопасность** → `references/architecture.md` (статичный сайт + `content.json` + админка + CSP).
5. **Пациенты и кейсы** → `references/patients.md`. Жёсткие правила, без исключений.
6. **Юридический минимум** → `references/legal.md` (что обязательно, что проверено по закону, что — нет).
7. **Хостинг в России** → `references/hosting-yandex-cloud.md` (Object Storage + Cloud DNS + Certificate Manager + автовыкладка).
8. **SEO** → `references/seo.md`.
9. **Уведомление в Роскомнадзор** → `references/rkn-notification.md` (поле за полем по реальной форме pd.rkn.gov.ru).

## Неснимаемые правила

- Фото и снимки пациентов — только с **письменного** согласия; глаза закрыты чёрными кругами; со снимков убраны ФИО,
  даты рождения, номера карт, логотипы клиник. В публичные репозитории и внешние сервисы (Artifact и т. п.) — никогда.
- Лицо врача не ретушировать без прямой просьбы.
- Instagram/Facebook упоминать с пометкой: «*Instagram — продукт компании Meta, признанной экстремистской организацией в России»
  (у drshapovalov.ru — всплывающая подсказка у звёздочки).
- Никаких внешних CDN, шрифтов Google и счётчиков до согласия: всё своё, локально.
- Секреты (токены, ключи облака) — только в секретах GitHub/окружения, не в коммитах и не в чате.
- Пользователь часто сидит с телефона: шаги для него — короткие, по одному, с точными названиями кнопок; проси скриншоты.
- Что не проверено — так и говори: «не проверял», «подтвердить не могу».

## Чек-лист перед сдачей сайта

- [ ] Все факты подтверждены врачом; у общих утверждений есть источники.
- [ ] Кейсы — с согласием, обезличены, глаза закрыты (`patients.md`).
- [ ] Метрика/аналитика грузится только после «Принять»; отказ работает; есть кнопка «Настройки cookie».
- [ ] Политика конфиденциальности опубликована, в ней верный хостинг и дата редакции.
- [ ] Хостинг и все хранилища данных — в России; исходники с фото пациентов не лежат на GitHub/за рубежом.
- [ ] Уведомление в РКН подано (или врач осознанно отказался).
- [ ] HTTPS, www → без www, http → https; favicon; robots.txt, sitemap.xml; подтверждены Яндекс Вебмастер и Search Console.
- [ ] Проверка в браузере: консоль без ошибок, мобильная ширина 320–390 px без горизонтальной прокрутки.
