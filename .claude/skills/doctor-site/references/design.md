# Дизайн сайта врача

## Какие скиллы и зачем
- **`taste-skill`** (tasteskill v2): идея из предмета, а не из категории; инвентарь того, что есть только у этого врача
  (метод, инструмент, снимок, его подпись); `draw.mjs` даёт направления; `inspect.mjs` проверяет в браузере.
  Для сайта врача «живая вещь» — схема метода, а не слайдер с улыбками.
- **`impeccable`** (плагин): доводка — типографика, ритм, состояния, проверка финала по контракту направления.
- **`awesome-design-md`**: 84 DESIGN.md известных сайтов — брать **систему** (шкала кеглей, отступы, радиусы, кнопки), не бренд.
- **`hallmark`**: проверка «AI-слопа» (sloplint).
- Видео о сайте — `brag` (полный, HyperFrames) или `brag-slim`.

## Что сработало у drshapovalov.ru
- Палитра: тёмный «void» `#05080a`, глубокий `#0a1513`, изумруд `#164236`, слоновая кость `#ede8de`, золото `#d6b266`/`#f0d48e`.
  Медицинский сайт не обязан быть бело-голубым; спокойный тёмный с одним акцентом читается как «дорого и серьёзно».
- Шрифты: Unbounded (заголовки) + Manrope (текст), **локальные woff2** (OFL), без Google Fonts.
- Фон — волна Vanta (three.js), плавная прокрутка Lenis, GSAP ScrollTrigger; при «уменьшить движение» — выключено.
- Подпись врача золотом «пишется пером» (маска из штрихов).
- Знак-монограмма «Ш.» → аватар, водяной знак, favicon (ico 16/32/48 + svg + apple-touch 180).
- Фото кейсов в лайтбоксе; чувствительные — под размытием.

## Правила
- Мобильная ширина 320–390 px: длинные заголовки и DOI — `hyphens:auto; overflow-wrap:anywhere`.
- Контраст WCAG AA; фокус видимый; кнопки ≥ 44 px.
- Проверять в настоящем браузере (Playwright / `playwright-cli`): консоль без ошибок, нет горизонтальной прокрутки.
- Не менять утверждённый врачом дизайн без запроса.
