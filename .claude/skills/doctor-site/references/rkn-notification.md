# Уведомление в РКН для врача-физлица: поле за полем (форма pd.rkn.gov.ru, ноябрь 2026)

Форма: pd.rkn.gov.ru/operators-registry/notification/form/ (из облака не открывается — врач заполняет сам, ты подсказываешь
по скриншотам). Подача с входом через ЕСИА (Госуслуги); подтверждение приходит на e-mail. Черновик можно сохранить.

- **Регион регистрации**, тип оператора **«Физическое лицо»**, ФИО, паспорт, СНИЛС — врач сам (не сохраняй и не пересылай эти данные).
- **Адрес** (публичен в реестре — предупреди). Внимание: e-mail — в поле «Адрес электронной почты», не в «Факс».
- **Регионы обработки**: где врач реально работает с данными (например, Москва).
- **Цели** (каждая — «Добавить цель обработки»; если цели нет в списке — «иная» с текстом):
  1. Публикация клинических случаев: пол, иные (возраст — в поле расшифровки «иные»), фото-видео изображение лица,
     **сведения о состоянии здоровья**; биометрию НЕ отмечать (фото не для установления личности);
     субъекты — законные представители + иные («пациенты, в т. ч. несовершеннолетние»); основание — согласие;
     действия — сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, передача,
     распространение, удаление, уничтожение; способы — смешанная / без передачи по внутренней сети / с передачей по Интернет.
  2. Учёт посещаемости: «сведения, собираемые посредством метрических программ»; субъекты — «Посетители сайта»;
     автоматизированная.
  3. Ответы на обращения: ФИО, телефон, e-mail, иные (текст обращения), здоровье — если сообщено.
- **Меры ст. 18.1/19** и **средства обеспечения безопасности** — текстом, только то, что реально сделано.
- **Шифровальные средства**: «используются» означает сертифицированные СКЗИ (форма просит класс КС1–КА и серийные номера) —
  для сайта с HTTPS выбирать **«не используются»**.
- **Дата начала** — первая публикация данных (у drshapovalov.ru 01.11.2026 по истории репозитория).
- **Срок** → «Условие окончания»: отзыв согласия; достижение цели; прекращение работы сайта.
- **Трансграничная передача** — честно (см. legal.md, GitHub!).
- **Базы данных**: страна, «Адрес ЦОДа» (справочник ФИАС), собственный ЦОД — нет, организация, ответственная за хранение
  (юрлицо, ОПФ, наименование, ОГРН, ИНН, адрес). Для Метрики — ООО «ЯНДЕКС», Москва, ул. Льва Толстого, 16
  (по условиям Метрики от 07.08.2026); ИНН 7736207543, ОГРН 1027700229193 — по агрегатору Saby, статус там противоречив, сверять в ЕГРЮЛ.
- **ГИС («Контакт №1»)** — пустой блок мешает отправке: нажать «удалить».
- Внизу — два флажка (ознакомлен; согласие на передачу), иначе «Вы не дали согласия на передачу информации».
