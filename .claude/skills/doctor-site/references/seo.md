# SEO сайта врача

- Title: «Фамилия Имя Отчество — специальность, степень | Город»; description — одна фраза из первого экрана.
- JSON-LD `@graph`: Physician + WebSite (+ MedicalOrganization клиники), без выдуманных отзывов и рейтингов.
- Яндекс Вебмастер: мета-тег `yandex-verification` + HTML-файл `yandex_<код>.html`; добавить sitemap; «Переобход страниц».
- Google Search Console: мета-тег `google-site-verification`; отправить sitemap.
- Отдельные страницы под запросы пациентов: метод (`/lechenie/<метод>/`), список кейсов и страница каждого кейса.
- `prerender.cjs`: контент в HTML без JS — поисковики видят текст.
- IndexNow (Яндекс, Bing): ключ-файл в корне, пинг адресов из sitemap после изменения текстов.
- Яндекс индексирует медленно (у нас Google — в первый же день, Яндекс — дни/недели); проверить `site:домен` можно
  только из браузера пользователя — из облака Яндекс показывает капчу.
- Метрика: цели JS-событий `reachGoal` на клики телефон/почта/Telegram/Instagram/ПроДокторов.
- Ссылка на сайт — во всех профилях врача (ПроДокторов, соцсети, страница клиники).
