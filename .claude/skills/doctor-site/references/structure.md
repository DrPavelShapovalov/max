# Структура и тексты сайта врача

Разделы (drshapovalov.ru, одна страница + отдельные страницы для поиска):
1. **Первый экран**: ФИО крупно, одна строка «кто и для кого» (специальность, степень, клиника, город,
   «Лечу детей и подростков»), фото врача, подпись. Две кнопки: записаться (колл-центр клиники) и связаться.
2. **Цифры** (`readings`): стаж, статьи, доклады — только подтверждённые.
3. **Для кого** (`audience`): вкладки «Родителям / Коллегам» — один и тот же сайт, разная глубина текста (`*Pro`-поля).
4. **Метод** (`distraction`): живая схема (у нас «Как растёт кость» — SVG-челюсть раздвигается при прокрутке,
   миллиметры на счётчике, этапы Операция → Пауза → Удлинение → Покой). Одна интерактивная вещь из сути работы врача
   сильнее десятка карточек.
5. **Направления** (`directions`) со ссылками на страницу метода и профильные кейсы.
6. **Кейсы** (`cases`): описание, цифры «до/после», снимки, согласие; у каждого — отдельная страница `/kejsy/<slug>/`.
7. **Как проходит лечение** (`steps`), **Наука** (`science`: статьи с DOI, доклады), **Где работаю**, **Контакты**.
8. **Словарь терминов** (`terms`): `[[ключ|слово]]` в тексте → всплывающее пояснение.
9. **Подвал**: пометка Meta, ссылка на политику, «Настройки cookie».

Тексты: просто и со вкусом, без пафоса и обещаний результата; правила постов — `branding/dr-shapovalov/collage/POSTS.md`
и `CONTENT-PLAYBOOK.md`. Английская версия — `content.en.json`, переключатель RU/EN.
