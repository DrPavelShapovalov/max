# OSSA 4 — планнер остеотомии и дистракции нижней челюсти

> Полностью переработанная версия (ранее «OSSA 3D» / «КДО-Планировщик 3D»).
> Настольное приложение (Windows, Electron) + веб-версия.

Планирование дистракционного остеогенеза нижней челюсти на 3D-модели: отделение
челюсти, остеотомия в углу/ветви и перемещение фрагмента дистрактором заданного
вектора.

> ⚠️ Прототип для научной и образовательной работы. Все расчёты — вспомогательный
> ориентир; клиническое решение принимает врач.

## Что изменилось в v4 (и зачем)

Раньше 3D строился автосегментацией: воксельная эрозия пыталась «разорвать» тонкие
сращения и угадать, где челюсть. На реальных КТ это ненадёжно — **там, где смыкаются
зубы, нижняя челюсть оказывается единой связной деталью со всем черепом**, и её не
удавалось корректно отделить и спланировать.

v4 отказывается от автосегментации в пользу **понятного потока 1‑2‑3**, где всё решает
хирург:

### Шаг 1. Отделить нижнюю челюсть
Нижняя челюсть «приклеена» к черепу в местах контакта (зубы, иногда сустав).
Инструмент **«Разорвать контакт»** удаляет небольшую зону треугольников в точке клика —
рвём мостик. Затем **«Отделить НЧ»** раскладывает модель на **связные компоненты**:
как только мостики разорваны, челюсть становится отдельной деталью и отщёлкивается
сама (union-find по сваренным вершинам) — без угадывания вокселями.

### Шаг 2. Остеотомия в углу
Ставим **секущую плоскость** на угол/ветвь, доворачиваем по линии распила и режем
челюсть на **проксимальный** (с мыщелком) и **дистальный** (тело) фрагменты.

### Шаг 3. Дистрактор — вектор
Выбираем вектор (перпендикуляр к распилу / сагиттально / вертикально / сочетанно),
длину и аппарат (прямой КДА‑180 или криволинейный). Ползунок **дистракции** двигает
дистальный фрагмент по прямой или по дуге; показываются регенерат, длина и угол.
Режим **«рельс»** ограничивает ручное перетаскивание строго по вектору.

## Загрузка данных

- **STL** — экспорт из вашей программы сегментации КТ (3D Slicer, Mimics и т.п.).
  Самый надёжный вход; можно несколько файлов.
- **DICOM** — папка серии; 3D-кость строится изоповерхностью по порогу HU (локально,
  офлайн). Поддержаны сжатые DICOM (RLE, JPEG Lossless/LS/2000, baseline).
- **Демо‑модель** — условный «череп + НЧ», сваренный только через зубные контакты,
  чтобы сразу попробовать весь поток без данных.

## MPR-срезы (кнопка «▦ Срезы»)

Рядом с 3D — колонка ортогональных срезов КТ (аксиал/коронар/сагиттал) с окном
**WC/WW** (пресеты «Кость»/«Мягкие ткани»), прокруткой срезов и перекрестием.
Доступно после загрузки DICOM или демо-модели (у неё есть синтетический объём).

## Авто-подбор криволинейного КДА

В Шаге 3 задаёшь **требуемый угол коррекции** (°) и «Подобрать КДА» — программа
выбирает аппарат, чья дуга ближе всего к нужному повороту регенерата
(поворот = 180 − «цифра» аппарата), и показывает рекомендованную модель, реальный
угол и радиус дуги.

## Протокол PDF

Кнопка «⬇ Протокол PDF» формирует одностраничный протокол: пациент/№, дата,
снимок 3D-плана, параметры дистракции (подвижный фрагмент, вектор, длина, аппарат,
поворот, радиус дуги) и список измерений. Кириллица рендерится через canvas, затем
вкладывается в PDF (jsPDF) — работает офлайн.

## Прочее

- Объекты сцены: выбор, видимость, переименование, удаление; гизмо «Сдвиг/Поворот».
- Измерение длины (2 точки), экспорт **STL** объекта или всего плана, сохранение/
  загрузка плана **.ossa**. Undo (Ctrl+Z).

## Как получить установщик (.exe)

1. Вкладка **Actions** репозитория → workflow сборки вьюпорта (Windows).
2. Последний запуск → **Artifacts** → установщик `OSSA-4-Setup-*.exe`.
3. Запусти, установи — работает офлайн.

## Разработка

```bash
cd viewer
npm install
npm run dev          # веб-версия (http://localhost:5173)
npm run build        # сборка в dist/
npm run dist         # Windows-установщик (на Windows)
```

## Архитектура (src/)

| Файл | Назначение |
|------|-----------|
| `app.js` | оркестратор: сцена, поток 1‑2‑3, объекты, экспорт, UI |
| `geometry.js` | ядро: связные компоненты (union-find), разрыв контакта, STL I/O |
| `cut.js` | рассечение меша плоскостью на два фрагмента |
| `distractors.js` | библиотека КДА (прямой/криволинейный), геометрия дуги |
| `demo.js` | демо-модель череп+НЧ + синтетический КТ-объём для MPR |
| `mpr.js` | срезы КТ (аксиал/коронар/сагиттал) с окном WC/WW и перекрестием |
| `mc.js` | изоповерхность кости из КТ (surface nets + сглаживание Тобина) |
| `dicom.js`, `decode.js` | чтение DICOM-серии и декодеры сжатия |
