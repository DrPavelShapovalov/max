# КДО-Планировщик 3D

Настольное приложение (Windows, Electron) для просмотра КТ/МСКТ в формате DICOM,
построения мультипланарных срезов (MPR) и 3D-реконструкции костных структур.

> ⚠️ Прототип для научной и образовательной работы. **Не является медицинским
> изделием** и не предназначен для принятия клинических решений без верификации.

## Возможности (этап 1)

- Загрузка серии DICOM (папка) — обработка полностью локальная, данные никуда не уходят.
- MPR: аксиальная, коронарная, сагиттальная плоскости с прицелом и прокруткой.
- Окно/уровень (пресеты «Кость», «Мягкие ткани»).
- 3D-реконструкция кости по порогу HU (изоповерхность), вращение/масштаб.

Поддерживаются несжатые DICOM (Little Endian). Сжатые (JPEG/JPEG2000) —
в следующем обновлении.

## Как получить установщик (.exe)

1. Вкладка **Actions** репозитория → workflow **Build 3D Viewer (Windows)**.
2. Последний запуск → раздел **Artifacts** → `KDO-Planner-3D-Windows-Installer`.
3. Внутри `KDO-Planner-3D-Setup-*.exe` — запусти, установи, работает офлайн.

## Разработка

```bash
cd viewer
npm install
npm run dev          # веб-версия для разработки (http://localhost:5173)
npm run dist         # собрать Windows-установщик (на Windows)
```

## Возможности (этап 2)

- Виртуальная остеотомия: секущая плоскость (аксиальная/коронарная/сагиттальная
  + наклоны + положение), распил модели на два фрагмента.
- Подвижный фрагмент: дистракция «наружу» вдоль нормали, боковой сдвиг, поворот.

## Возможности (этап 3)

- Ручное/локальное размещение плоскости распила (гизмо) + область (ROI) —
  отпиливается только выбранный участок (угол/ветвь), а не всё сразу.
- Свободное перетаскивание любого фрагмента (гизмо: сдвиг/поворот).
- Библиотека дистракторов КДА-30/50/70/100/180 и «Спланировать КДО».
  «Цифра» аппарата — угловая кривизна дуги в **градусах** (не мм, не радиус).
  Задаётся длина дистракции и требуемый угол коррекции → программа подбирает
  аппарат по углу, выводит радиус дуги (R = длина / угол) и перемещает
  фрагмент по этой дуге для достижения симметрии.

## Возможности (этап 4)

- **Карандаш (распил от руки):**
  - *Линия остеотомии (локально)* — проведите линию **через всю ширину кости**;
    челюсть делится на два больших фрагмента (дистальный/медиальный), а череп
    и дальняя кость остаются целыми (связь рвётся только в полосе у линии).
    «Поменять фрагмент» выбирает, какой из двух подвижный (напр., медиальный).
  - *Контур области* — обведение зоны (вырубка вдоль луча взгляда).
- **Плоскость-окно:** голубую секущую плоскость можно скрыть (для карандаша
  она прячется сама) и **менять её ширину/длину** — уменьшив прямоугольник и
  наведя его на угол НЧ, распил захватит только то, что внутри рамки.
  Плоскость двигается/вращается гизмо в трёх плоскостях.
- **Зона аппарата (точки):** «Отметить зону аппарата» → 2 клика по кости
  задают, где стоит КДА; «Спланировать КДО» строит дугу именно в этой зоне.
- Точный распил плоскостью и локальный ROI-распил сохранены.

## Возможности (этап 5) — симметрия

- **Зеркало здоровой стороны:** полупрозрачная зеркальная копия по срединной
  плоскости (регулируется ползунком «Средняя») — видно цель симметрии.
- **Здоровый ориентир:** клик по здоровому гониону/точке — её зеркало
  становится целью на поражённой стороне.
- **Дистракция до симметрии (авто-КДО):** программа сама считает
  необходимый угол коррекции и величину дистракции (мм), **подбирает
  аппарат** (КДА-30/50/70/100/180 по кривизне дуги), строит дугу вокруг
  зоны остеотомии и показывает **остаточную асимметрию**.

## Возможности (этап 6)

- **Интерфейс по блокам:** слева — распил/остеотомия, справа — дистрактор и
  симметрия, снизу — измерения и экспорт. Панели сворачиваются.
- **Линия карандашом** = локальная режущая плоскость: делит кость на части
  «выше/ниже линии» только в зоне штриха (не разваливает череп). «Поменять
  фрагмент» — какая часть подвижна.
- **Плоскость-рамка** с шириной/высотой/**толщиной**: рамка — это объём;
  толщина не даёт «прошить» череп насквозь, можно поймать только угол.
- **Дистракция-шарнир:** фрагмент вращается вокруг зоны остеотомии
  (не «улетает»).
- **Симметрия:** средняя плоскость по 3 точкам (устойчиво к наклону головы),
  зеркало здоровой стороны, авто-дистракция до симметрии.
- **Измерения:** длина (2 точки), угол (3 точки), объём фрагмента (см³).
- **Экспорт:** STL готового плана (для 3D-печати) и HTML-протокол планирования.
