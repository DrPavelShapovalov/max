# STL-модели криволинейного КДА (патент RU2772023C1)

Внутриротовой компрессионно-дистракционный аппарат для нижней челюсти
(ООО «КОНМЕТ»). Модель воспроизводит аппарат **в собранном виде** — как на
**фиг. 28** патента (фотография реального изделия): криволинейная зубчатая
**рейка** радиуса R уходит в одну сторону, в центре **плотно** собраны две
**клеверные пластины-«бабочки»**, из центрального узла (**ползун** с **червяком**)
в другую сторону прямо уходит **гибкий привод** (поз. 30) с шестигранным
хвостовиком. Привод гибкого типа (витой), но моделируется **прямым** — на фото
он лишь лежит изогнутым, потому что гибкий.

| Файл | Радиус дуги рейки R |
|------|--------------------|
| `KDA_R40.stl` | 40 мм (самый криволинейный) |
| `KDA_R50.stl` | 50 мм |
| `KDA_R70.stl` | 70 мм |
| `KDA_R100.stl` | 100 мм |
| `KDA_R180.stl` | 180 мм (почти прямой) |

Модели параметрические — генерируются из [`../../src/kda.js`](../../src/kda.js)
функцией `buildKDA(R)`. В планнере OSSA аппарат ставится кнопкой **«🩺 Поставить
КДА»** (панель «Распил»): отметь 2 точки аппарата и выбери радиус R; аппарат можно
двигать/вращать гизмо и экспортировать в STL («STL объекта»).

**Высокая детализация** (~8200 треуг.) по собранному виду (фиг. 4, 5, 24, 25, 28):

- **Рейка 1** — криволинейная дуга радиуса R с настоящими трапециевидными
  **зубьями 6** (шаг ~1.15 мм, наклон к радиусу);
- **Пластины 2 и 4** — «клеверные/бабочка»: по две трилистниковые лепестки
  (3 **зенкованных** отверстия 29/7 в каждой, фиг. 25); собраны плотно у
  центрального узла — одна веером вверх, другая вниз (4 трилистника, как на фиг. 28);
- **Ползун 3 / корпус 9** — паз под рейку, арка-гнездо червяка, выступы 36,
  пружинящие элементы 15;
- **Червяк 10** — конический сердечник с винтовой **резьбой 34** в зацеплении с
  зубьями рейки;
- **Кардан** — вилки 16/35 + крестовина 17;
- **Гибкий привод 30** — прямой витой вал (гибкого типа) с муфтами-проточками 25
  и шестигранным хвостовиком 28.

> Пропорции клинические (пластины под винты 2.0–2.4 мм, рейка ~4×1.7 мм, привод
> ~Ø2.2 мм). В патенте числовых размеров нет — геометрия воспроизводит форму по
> чертежам (фиг. 1–28) и фотографии собранного изделия (фиг. 28). Радиус R —
> главный параметр дуги. Для модели 1:1 нужны реальные размеры (ширина/толщина
> рейки, шаг зубьев, Ø и шаг отверстий и т.д.).
