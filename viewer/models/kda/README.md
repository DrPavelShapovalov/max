# STL-модели криволинейного КДА (патент RU2772023C1)

Внутриротовой компрессионно-дистракционный аппарат для нижней челюсти
(ООО «КОНМЕТ»): криволинейная зубчатая **рейка** радиуса R + костная **пластина**
(неподвижный фрагмент), **ползун** с **червяком** + костная пластина (подвижный
фрагмент) и **привод** наружу.

| Файл | Радиус дуги рейки R |
|------|--------------------|
| `KDA_R40.stl` | 40 мм (самый криволинейный) |
| `KDA_R50.stl` | 50 мм |
| `KDA_R70.stl` | 70 мм |
| `KDA_R100.stl` | 100 мм |
| `KDA_R180.stl` | 180 мм (почти прямой) |

Модели параметрические — генерируются из [`../../src/kda.js`](../../src/kda.js)
функцией `buildKDA(R)`. В планнере OSSA аппарат ставится кнопкой **«🩺 Поставить
КДА»** (панель «Распил»): отметь 2 точки аппарата и выбери радиус R; аппарат можно
двигать/вращать гизмо и экспортировать в STL («STL объекта»).

**Высокая детализация** (~6400 треуг.): настоящие трапециевидные **зубья** рейки
(шаг ~1.2 мм, наклон к радиусу), **червяк** с винтовой резьбой, корпус ползуна с
выступами 36 и пружинящими элементами 15, **зенкованные** отверстия 29/7 в
клеверных пластинах, **карданный** привод (вилки 16/35, крестовина 17, кольцевые
проточки 25, шестигранный хвостовик 28).

> Пропорции клинические (пластины ~Ø2.7 мм под винты 2.0–2.4 мм, рейка ~4×1.7 мм,
> привод ~Ø2.2 мм). В патенте числовых размеров нет — геометрия воспроизводит форму
> по чертежам (фиг. 1–28). Радиус R — главный параметр дуги. Для модели 1:1 нужны
> реальные размеры (ширина/толщина рейки, шаг зубьев, Ø и шаг отверстий и т.д.).
