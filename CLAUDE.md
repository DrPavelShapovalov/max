# Правила работы в этом проекте

## PDF и документы — ОБЯЗАТЕЛЬНОЕ ПРАВИЛО

**При любом упоминании или загрузке PDF/DOCX/PPTX файла:**

1. НЕ пытаться читать файл напрямую
2. СРАЗУ конвертировать через:
   ```bash
   python3 /home/user/max/pdf2md.py "<path_to_file>" /tmp/converted.md
   ```
3. Читать результат: `Read /tmp/converted.md`
4. Работать с извлечённым текстом

Пути загрузок: `/root/.claude/uploads/<session_id>/<filename>`
