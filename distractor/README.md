# КДА-Актив — планировщик активации дистрактора

Приложение для ведения **активации компрессионно-дистракционных аппаратов (КДА)**
при дистракционном остеогенезе нижней челюсти: кто, когда и как крутит дистрактор,
с напоминаниями на телефон. Идея — как у приложений для аппарата Илизарова, но под
челюстные КДА и наш протокол.

> ⚠️ Вспомогательный планировщик. Решение и контроль — за лечащим врачом.

## Что умеет (v1.0)

- **Паспорт пациента**: ФИО, дата рождения → **возраст автоматически**, код пациента.
- **Операция и дистракция**: дата операции, дата начала активации → автоматически
  показывает, **на какие сутки** после операции идёт активация. Одно-/двусторонняя.
- **Выбор КДА** на каждую сторону: `R30, R40, R50, R70, R100, R180` или `820 (прямой)`.
- **Автоматический график активаций** по протоколу:
  - **820 (прямой)** — ⟳ по часовой, **1 полный оборот** за активацию (0,5 мм), 2×/день → 1 мм/сут;
  - **R-серия** — ⟲ против часовой, **½ оборота** за активацию (0,5 мм), 2×/день → 1 мм/сут.
- **УЗИ-коррекции**: по картине регенерата (гипер-/гипо-/нормотрофический) можно
  **дробить темп на 3×/день (08/16/00)** и менять мм/сут — с обоснованием; график
  перестраивается с указанной даты.
- **Отметки «покрутил»** (журнал активаций), ближайшая активация с обратным отсчётом.
- **Напоминания**: экспорт в **Календарь (.ics)** — импорт в «Календарь» iPhone/Google,
  напоминания 08:00/20:00 приходят сами на весь период; плюс уведомления в самом
  приложении, пока оно открыто.
- **База случаев** в устройстве (localStorage) + экспорт/импорт JSON.

## Как запустить / скачать

- **На телефоне (iPhone/Android)**: открыть размещённую веб-версию в браузере →
  «Поделиться» → **«На экран Домой»** (устанавливается как приложение, работает офлайн).
- **Windows (.exe)**: сборка установщика — автоматически в GitHub Actions при изменении
  `distractor/`. Actions → **Build КДА-Актив (Windows)** → Artifacts →
  `KDA-Activ-Windows-Installer` → `KDA-Activ-Setup-1.0.0.exe`.

Локально:
```bash
cd distractor
npm install
npm start      # окно Electron
npm run dist   # собрать .exe (на Windows)
```

## Структура

- `app/index.html` — само приложение (один файл, без зависимостей; офлайн).
- `app/manifest.webmanifest`, `app/sw.js`, `app/icon-*.png` — PWA (установка на телефон).
- `main.js` — обёртка Electron (Windows-окно).
