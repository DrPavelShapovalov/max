# MaxVPN

Свой VPN на собственном сервере: настольное приложение подключается к вашему VPS
по SSH, разворачивает там WireGuard или AmneziaWG, заводит устройства и поднимает
туннель.

## Что здесь есть

```
vpn/
├── server/
│   ├── install-server.sh   установка и настройка сервера (Debian, Ubuntu)
│   └── maxvpn              управление устройствами на сервере
└── client/                 настольное приложение на Electron
    ├── src/keys.js         генерация ключей X25519
    ├── src/config.js       сборка клиентского .conf
    ├── src/ssh.js          выполнение команд на сервере
    ├── src/tunnel.js       запуск и остановка туннеля
    └── test/run.js         проверки без сервера: node test/run.js
```

## Два протокола на выбор

**WireGuard** — быстрый и совместимый со всеми штатными клиентами, но его трафик
опознаётся системами анализа по характерной сигнатуре.

**AmneziaWG** — форк WireGuard, добавляющий обфускацию: мусорные пакеты в начале
сессии и изменённые заголовки, за счёт чего трафик перестаёт выглядеть как
WireGuard. Параметры задаются полями `Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4`
в секции `[Interface]`; установщик генерирует их случайно в рекомендованных
диапазонах ([документация протокола][awg-kmod]).

Параметры `S1`, `S2` и `H1`–`H4` должны совпадать на сервере и клиенте — поэтому
сервер отдаёт их клиенту, и тот подставляет их в свой конфиг автоматически.

## Требования

К серверу:

* Debian или Ubuntu, доступ под `root` по SSH (пароль или ключ);
* белый IP-адрес и открытый UDP-порт;
* для AmneziaWG — ядро, допускающее сборку модулей. На OpenVZ и LXC модуль
  не соберётся, установщик это обнаружит и предложит перейти на обычный
  WireGuard.

К компьютеру, с которого подключаетесь:

* Node.js 18 или новее для запуска клиента из исходников;
* установленный WireGuard или AmneziaWG — приложение управляет штатными
  утилитами системы, своего драйвера туннеля в нём нет (см. «Ограничения»).

## Запуск клиента

```bash
cd vpn/client
npm install
npm start
```

В окне: адрес сервера, доступ по SSH, протокол — и «Установить и настроить
сервер». Установка занимает 1–3 минуты, из них большая часть — сборка модуля
ядра для AmneziaWG.

## Настройка сервера вручную, без приложения

Приложение не делает ничего, чего нельзя сделать руками:

```bash
scp vpn/server/install-server.sh vpn/server/maxvpn root@ВАШ_СЕРВЕР:/root/
ssh root@ВАШ_СЕРВЕР
bash /root/install-server.sh --mode awg

maxvpn add phone        # ключ создаст сервер
maxvpn qr phone         # QR-код для приложения на телефоне
maxvpn list
maxvpn remove phone
```

`maxvpn add ИМЯ --pubkey КЛЮЧ` добавляет устройство, чей приватный ключ создан
на самом устройстве и серверу неизвестен — так работает настольный клиент.

Конфиги, которые выдаёт `maxvpn`, — обычные файлы формата `awg-quick`, их
понимают приложения AmneziaWG и AmneziaVPN, а в режиме `--mode wg` — любой
клиент WireGuard.

## Безопасность

* Приватный ключ настольного клиента создаётся на вашем компьютере и на сервер
  не передаётся: по SSH уходит только публичный ключ.
* Пароль SSH нигде не сохраняется — он живёт в памяти только на время операции.
  В профиль пишутся адрес, имя пользователя и путь к ключу.
* Для каждого устройства генерируется дополнительный общий ключ `PresharedKey`.
* Ключ сервера и список устройств лежат в `/etc/maxvpn` с правами `600`.
* Повторный запуск установщика не пересоздаёт ключи — ранее выданные конфиги
  продолжают работать.

## Ограничения

Честный список того, чего приложение не делает:

1. **Своего драйвера туннеля нет.** Подключение выполняется штатными
   `wg-quick`, `awg-quick` или `wireguard.exe`. На Linux требуются права root
   (используется `pkexec` или `sudo`), на Windows — запуск от администратора.
2. **AmneziaWG в Windows и macOS приложение не поднимает само.** Конфиг
   выгружается кнопкой «Экспортировать .conf» и импортируется в клиент
   AmneziaVPN или AmneziaWG. В Linux `awg-quick` вызывается напрямую.
3. **Протокол только один.** В AmneziaVPN есть также XRay/VLESS, OpenVPN
   с Cloak и Shadowsocks — здесь их нет.
4. **IPv6 внутри туннеля не настраивается**, маршрутизируется только IPv4.
5. **Проверено частично.** Модули генерации ключей и сборки конфига покрыты
   тестами (`npm test` в `vpn/client`), логика управления устройствами
   проверялась на заглушках. Установка на реальный VPS и подключение
   к нему не проверялись — это можно сделать только на вашем сервере.
