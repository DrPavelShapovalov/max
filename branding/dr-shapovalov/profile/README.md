# Силуэт-портрет — вторая часть системы

Минималистичный силуэт в профиль: причёска, очки, монограмма «Ш.» на воротнике
(та же точка, что и в основном знаке — единая система с `../mark-dark.svg`).

## Роль в системе

Это **не замена** знаку «Ш.» из корневой папки, а второй элемент той же
айдентики:

- `mark-dark.svg` / `mark-white.svg` (уровень выше) — подпись под постами,
  водяной знак, маленькие размеры.
- `profile-dark.svg` / `profile-light.svg` (эта папка) — аватар,
  обложка канала, крупные форматы, где стоит показать лицо, а не только инициал.

## Файлы

- `profile-dark.svg`, `profile-light.svg` — мастер-векторы (viewBox 0 0 240 300).
- `avatar-profile-dark.png`, `avatar-profile-light.png` — готовые квадратные
  аватарки 1080×1080 (композиция с полями под текст/хэндл справа).
- `alt-a-clean.svg` — вариант без монограммы (чистый силуэт).
- `alt-b-suture.svg` — вариант с едва заметной линией черепного шва
  (анатомическая отсылка к специальности, без монограммы).

Три варианта разобраны с обоснованием в бренд-гайде (артефакт в диалоге).
