# Обложки рилсов

1080×1920, чёрный фон с цветом-акцентом, золотой ободок, фото с золотым контуром и пунктиром,
заголовок сверху, снизу знак без подложки: «челюстно-лицевой хирург» и золотая подпись Dr. Shapovalov на мягкой тени.
Заголовок и знак стоят в центральной зоне 3:4 (y 240–1680), поэтому сетка профиля их не обрезает.
Рядом с каждой обложкой сохраняется `*-grid.png` — как она выглядит в сетке.

Палитры: `emerald` (чёрный + изумруд + золото, по умолчанию) и `ivory` (светлая, бронза вместо золота).
Строки заголовка: `plain` — светлый текст, `gold` — золото, `band` — на плашке цвета-акцента.
Символ `→` рисуется стрелкой.

```bash
python3 getfonts.py                 # один раз
python3 render.py covers.json       # covers.json по образцу covers.example.json
```

Фото — PNG с прозрачным фоном (вырезать можно `rembg`). Нужны Pillow, numpy, opencv.
Фото пациентов на обложку не ставить; интраоперационные кадры Instagram скрывает.
