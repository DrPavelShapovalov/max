# Реальный силуэт — чёрный + золото

Силуэт вырезан сегментацией из твоего настоящего фото, а не нарисован
кривыми от руки. Два предыдущих эскиза (профиль, потом придуманный
анфас) не получились именно потому, что были нарисованы вслепую —
здесь форма головы, причёски и очков настоящая, взята с фото.

## Как сделано

1. Сегментация фото (отделение человека от фона по маске).
2. Кадрирование под портрет — голова и плечи, без вытянутой руки с телефоном.
3. Форма очков и их наклон посчитаны по яркости пикселей на фото
   (тёмная оправа против светлой кожи), а не нарисованы заново.
4. Заливка сплошным цветом: силуэт + инверсия для оправы очков.

Поза — как на фото (лёгкий наклон головы, это селфи), не выпрямлял
искусственно.

## Файлы

- `mark-light.png`, `mark-dark.png` — мастер-версии, прозрачный фон,
  высокое разрешение (780×915). Это НЕ вектор — форма получена из фото.
- `avatar-light.png`, `avatar-dark.png` — квадратные аватарки 1080×1080.
- `watermark-light-*.png`, `watermark-dark-*.png` — прозрачные PNG
  (128/256/512 px) для подписи на фото.

## Цвета

- Силуэт (светлая версия) / очки (тёмная версия): `#111111`
- Силуэт (тёмная версия) / очки (светлая версия): `#A9822E` (светлый фон) / `#D4AF5A` (тёмный фон)

## Статус

Третий эскиз портрета. Два предыдущих (нарисованный профиль и
нарисованный анфас) удалены из репозитория — не получились. Знак «Ш.»
(`../mark-dark.svg`) остаётся рабочим вариантом на выбор — два разных
направления, не единая система.
