# Портрет анфас — чёрный + золото

Второй, независимый эскиз: фронтальный силуэт (причёска, очки), без букв
и монограмм. Отдельная палитра — чёрный/угольный + тёплое золото.

Пришёл на смену силуэту в профиль (`../profile/`, удалён — не получился:
читался как карикатура). Анфас устойчивее в векторе: не нужно рисовать
нос/подбородок сбоку, форма почти симметрична, узнаваемость держат очки.

## Файлы

- `mark-paper.svg` — чёрный силуэт, золотые очки (для светлого фона).
- `mark-black.svg` — золотой силуэт, чёрные очки (для тёмного фона).
- `avatar-paper.png`, `avatar-black.png` — готовые аватарки 1080×1080
  (чёрная версия — с тонким золотым кольцом).
- `watermark-light-*.png`, `watermark-dark-*.png` — прозрачные PNG
  (128/256/512 px) для подписи на фото.

## Цвета

- Силуэт (светлый фон): `#161513`
- Силуэт (тёмный фон) / кольцо: `#D4AF5A`
- Акцент (очки на светлом фоне): `#A9822E`

## Статус

Это альтернатива знаку «Ш.» (`../mark-dark.svg`), не дополнение к нему —
два разных направления на выбор, не единая система.
