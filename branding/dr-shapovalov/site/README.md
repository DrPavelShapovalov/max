# Сайт-визитка Dr. Shapovalov

| Файл | Что это |
|---|---|
| `content.json` | Весь текст сайта. Его меняет админка |
| `index.html` | Страница. Сама строится из `content.json` |
| `admin.html` | Админ-панель: разделы слева, форма в центре, живой сайт справа |
| `img/` | Портрет и золотая подпись |
| `build.py` | Собирает `dist/` для своего хостинга (добавляет `<!doctype>` и `<head>`, которые в Artifact добавляются сами) |

## Как поставить на хостинг (GitHub Pages)

1. `python3 build.py` → папка `dist/`.
2. Содержимое `dist/` положить в отдельный репозиторий (например `dr-shapovalov-site`) и включить
   Settings → Pages → Deploy from a branch → `main` / root.
3. Открыть `https://<ник>.github.io/<репозиторий>/admin.html` → раздел «Публикация»:
   владелец, репозиторий, ветка, папка (пусто, если сайт в корне), токен.

## Токен

GitHub → Settings → Developer settings → Fine-grained tokens. Доступ только к репозиторию сайта,
Permissions → Contents: Read and write, срок действия — 30–90 дней. Админка пускает только с токеном,
у которого есть право записи (проверка на GitHub). Без токена `admin.html` ничего не может изменить.
Токен хранится только в браузере: во вкладке (sessionStorage) или, если отмечено «Запомнить», в localStorage.
На адресе `*.github.io` «Запомнить» отключено: там все проекты аккаунта делят localStorage.
Если токен мог утечь — отзовите его на GitHub (Settings → Developer settings → Fine-grained tokens → Revoke).

## Разметка в текстах

`**жирный**`, `[[ключ|слово]]` — слово с пояснением из раздела «Словарь терминов».
Пустые поля на сайте не показываются; в предпросмотре админки они видны как «Добавить: …».

## Библиотеки (версии закреплены)

three.js r134, Vanta 0.5.24 (WAVES), Lenis 1.3.27, GSAP 3.12.5 + ScrollTrigger.
В предпросмотре на claude.ai они грузятся с CDN; на своём хостинге — из `vendor/` (копии из npm, см. `vendor/README.md`).
При «уменьшить движение» волна, плавная прокрутка и анимации не запускаются.

## Безопасность

- **CSP** (`<meta>` в `dist/`, ставит `build.py`): выполняются только свои файлы и встроенные скрипты с известным
  SHA-256; сторонние скрипты, `<object>`, `<base>` и отправка форм запрещены; админка ходит в сеть только к себе и `api.github.com`.
- **Без CDN** на своём хостинге: взлом CDN не даст чужому коду доступ к сайту и к токену админки.
- **Предпросмотр** в админке изолирован (`sandbox` без `allow-same-origin`): из него не прочитать хранилище с токеном.
- **Живой предпросмотр** сайт принимает только от своей админки (проверка источника и адреса сообщения).
- **Встраивание**: админка не открывается внутри чужой страницы (защита от «подставных» кликов).
- **Загрузка фото**: только настоящие JPEG/PNG/WebP (проверяются первые байты), имя файла очищается.
- **Картинки** публикуются без метаданных (EXIF, GPS, XMP); из `img/` на сайт попадают только изображения.
- **Тексты** из `content.json` экранируются, ссылки пропускаются только `https:`, `mailto:`, `tel:`, `#` и `img/`.
- GitHub Pages не даёт задавать HTTP-заголовки, поэтому `frame-ancestors` и HSTS недоступны; для своего домена
  включите в настройках Pages «Enforce HTTPS».
