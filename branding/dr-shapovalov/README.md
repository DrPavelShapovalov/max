# Знак Шаповалова — dr__shapovalov

Минималистичная монограмма «Ш» с точкой: три вертикальных штриха и опорная линия
(геометричная форма буквы «Ш»), тонкое кольцо-печать снаружи, точка снизу справа —
знак завершённости/подписи, как «Ш.» после инициала.

## Файлы

- `mark-dark.svg`, `mark-white.svg` — мастер-векторы (viewBox 0 0 100 100).
- `avatar-black.png`, `avatar-white.png` — готовые аватарки 1080×1080 для Instagram/Telegram.
- `watermark-dark-*.png`, `watermark-white-*.png` — прозрачные PNG знака (128/256/512 px) для водяного знака на фото.

## Правила использования

- Тёмная версия — на светлых фото и для аватарки на светлом фоне.
- Белая версия — водяным знаком на тёмных/клинических кадрах.
- Минимальный размер: 24×24 px (водяной знак), 512×512 px (аватар).
- Свободное поле вокруг знака: не менее 15% от его диаметра.
- Не вращать, не растягивать, не менять цвет частей по отдельности.
- Толщина штриха 5.5 / кольцо 1.4 (в системе viewBox 100×100) — не менять при ручном редактировании.
