# Анализатор КДО — десктоп-версия (Windows)

Функционально-морфометрический анализатор показаний к дистракционному
остеогенезу нижней челюсти. Свидетельство о государственной регистрации
программы для ЭВМ № RU 2026614230.

## Как получить установщик (.exe)

Установщик собирается автоматически на сервере GitHub при каждом изменении
папки `desktop/`.

1. Открой вкладку **Actions** в репозитории.
2. Выбери последний запуск workflow **Build Desktop (Windows)**.
3. Внизу, в разделе **Artifacts**, скачай `AnalizatorKDO-Windows-Installer`.
4. Внутри — `AnalizatorKDO-Setup-1.0.0.exe`. Запусти, пройди «Далее» —
   появится ярлык на рабочем столе и в меню «Пуск». Работает офлайн.

Запустить сборку вручную можно кнопкой **Run workflow** (workflow_dispatch).

## Локальный запуск для разработки

```bash
cd desktop
npm install
npm start        # запустить приложение
npm run dist     # собрать установщик в dist/ (только на Windows)
```

## Структура

- `app/index.html` — само приложение (полностью автономное, все библиотеки внутри).
- `main.js` — процесс Electron: открывает приложение в отдельном окне.
- `build/icon.ico` — иконка приложения.

## Синхронизация архива с Google Диском (v2.0)

Единая база КДО в вашей Google-Таблице: расчёты со всех компьютеров
(ординаторская, другой ПК, ваш аккаунт) собираются в один архив, а на головном
компьютере во вкладке **☁ Облако** видно, кто и что измеряет.

### Настройка (один раз, на вашем аккаунте Google)
1. Создайте Google-Таблицу «Архив КДО» на своём Google Диске.
2. **Расширения → Apps Script**, вставьте серверный код, впишите свой `TOKEN`.
   Код можно взять тремя способами: кнопка ⚙ → «📋 Показать код для Google»
   (окно теперь можно выделять и копировать) или «⬇ Скачать Code.gs» (сохранит
   файл), либо готовый файл [`apps-script/Code.gs`](apps-script/Code.gs) в репозитории.
3. **Развернуть → Веб-приложение**, доступ «Все», выполнять от вашего имени.
4. Скопируйте URL `…/exec`.

### На каждом компьютере
Кнопка **⚙** в правом верхнем углу → вставьте URL и TOKEN, укажите имя
кабинета/компьютера, включите автосинхронизацию. Готово — расчёты уходят в
общую таблицу; «☁ Облако → Обновить» подтягивает всё обратно.

> **152-ФЗ.** Отправка ФИО в облако — по решению правообладателя. Без галки
> «Отправлять ФИО» в облако уходят только инициалы + год рождения.

## Объективная оценка функциональных нарушений (v2.3)

Блок переведён с субъективных галочек на **конкретные окна под реальные бланки**:
название окна совпадает с названием параметра в исследовании. Врач просто вводит
число из заключения — программа сама сверяет с нормой и решает, начислять ли балл.
Окна сгруппированы по исследованиям (полисомнография / ЭМГ / окклюзия /
клинические / равновесие).

| Группа · параметр (как в бланке) | Откуда взять | Норма / балл | Вес |
|---|---|---|---|
| **ПСГ** · Индекс апноэ-гипопноэ (ИАГ / «А+Г»), эп./час | строка «А+Г» | < 5 (дети < 1) | 1.0 |
| **ПСГ** · Индекс десатураций (ODI), эп./час | «Количество десатураций … (индекс)» | < 5 | 0.7 |
| **ПСГ** · Минимальная сатурация SpO₂ за сон, % | «Минимальный уровень сатурации за время сна» | ≥ 90 % | 0.8 |
| **ПСГ** · Индекс храпа, эп./час | «Количество эпизодов храпа в час (индекс)» | < 30 | 0.5 |
| **ЭМГ** · Асимметрия сторон (по «Площадь, мкВ·мс») | сжатие: D и S, пара с бо́льшей разницей | < 15 % | 0.6 |
| **Окклюзия** · Нагрузка на сторону, % | T-scan: «Левый % / Право %» | 40–60 % | 0.5 |
| Открывание рта — межрезцовое, мм | линейкой | ≥ 35 (дети ≥ 30) | 0.7 |
| Дисфагия — EAT-10, баллы | сумма опросника | < 3 | 0.6 |
| Слюнотечение — саливация, мл/мин | сиалометрия | ≤ 7 | 0.3 |
| **Равновесие** · Площадь S (з), мм² | стабилометрия: столбец «S (з)» | < 99,5 (справочно) | — |

Норма ИАГ подстраивается под возраст (у детей < 14 лет порог < 1). Тяжёлые
отклонения получают повышающий коэффициент (ИАГ ≥ 30 → ×1.3, SpO₂ ≤ 85 % → ×1.3
и т. д.).

**Резервная галочка.** Если по методу не введена ни цифра, ни текст, рядом есть
галочка «нет данных — отметить вручную»: отметил → балл начисляется субъективно,
как раньше. Как только введено объективное значение, галочка гаснет и решение
принимается по цифре/тексту. Для логопеда так же: есть заключение → анализ текста,
нет заключения, но стоит галка → балл за нарушение речи ставится вручную.

> Пример (ПСГ Горбатенко): ИАГ 0,87 и ODI 0,25 → в норме; SpO₂ min 76 % → +1.0;
> индекс храпа 192,6 → +0.6. Пример (Ефимов): ЭМГ височные 32,34/75,06 →
> асимметрия 39,8 % → +0.7; T-scan «Право 63,7 %» → +0.5.

### Заключение логопеда (анализ текста)
У логопеда цифр нет — только текст. Поле **«Заключение логопеда»** разбирает
заключение по ключевым словам и решает, вызвано ли нарушение речи
недоразвитием нижней челюсти / прикуса (балл +0.4), иной причиной —
неврология, слух, функциональная дислалия (балл не начисляется) или обеими
(половинный балл +0.2). Учитываются и отрицания («с прикусом не связано»).
Это вспомогательная подсказка — окончательное решение за врачом.

## MOFI — Mandibular Osteo-Functional Index (v2.5)

Единый показатель 0–100, объединяющий морфологию (ИА/ИНЧ) и функцию, где **каждое
число объяснимо** (без «почему 1, а не 0.9»):

1. **Объективная тяжесть каждого показателя** `s ∈ [0…1]`:
   `s = (измерено − норма) / (тяжёлое − норма)`, обрезано в [0;1]. Для каждого
   метода заданы две опорные точки — норма (s=0) и «тяжёлое» (s=1). Если по методу
   стоит только галочка (без цифры) — s = 0.5.
2. **Вес-потолок `w`** по рангу угрозы (жизнеугрожающее 1.0 … низкое 0.3) — вклад
   метода `c = w · s`.
3. **Функция `F`** собирается «объединением» (noisy-OR): `F = 1 − Π(1 − cᵢ)` — одно
   тяжёлое жизнеугрожающее нарушение само даёт высокий вклад, мелкие накапливаются.
4. **Морфология `m`** нормируется из ИА/ИНЧ (ИА: 3→0, 20→1; ИНЧ: −5→0, −30→1).
5. **MOFI = 100 · (0.6·m + 0.4·F)** — морфология ведущая, функция усиливает.

Полосы: < 20 минимальны · 20–45 умеренные · 45–70 выраженные · ≥ 70 явные показания.
Показывается карточкой в результатах (с разбивкой вкладов) и в PDF-протоколе.
Пороги и веса в дальнейшем можно откалибровать по накопленной базе (архив/облако),
убрав остаток субъективности. Индекс — вспомогательный ориентир, решение за врачом.
