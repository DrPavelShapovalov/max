# ОРТОС ↔ Dolphin — карта паритета (recon)

Clean-room сравнение: что умеет Dolphin Imaging/Dolphin 3D (по **открытым**
материалам — продуктовые брошюры, независимые исследования) и что из этого
уже есть в ОРТОС. Повторяем функции и клинический поток, без кода/бренда/
контента оригинала; нормы и методики — общедоступные.

Источники (публичные): продуктовый лист Dolphin Imaging 11.95, брошюра 11.5,
независимые работы по суперимпозиции и анализу дыхательных путей (Angle
Orthodontist, JCO, PMC). Ссылки — в сообщении-отчёте.

## Чего нет в ОРТОС (gap-лист, по приоритету)

### #1 — Библиотека анализов ✅ *(реализовано)*
Dolphin: 400+ боковых анализов (Ricketts, McNamara, Steiner, Tweed, Jarabak,
Roth, Sassouni, McLaughlin, Downs, Bjork), фронтальные (Ricketts, Grummons),
настраиваемые; нормы по полу/возрасту/расе.
ОРТОС: **сделано** — переключатель «Анализ» на шаге 5: **ОРТОС (сводный,
детские нормы)** + классические **Steiner, Ricketts, McNamara, Jarabak, Downs,
Tweed, Wits**; каждый = свой список измерений + классические нормы метода.
Data-driven реестр метрик (`CEPH_METRIC`/`CEPH_ANALYSES`); для показателя без
нужной точки — подсказка, что поставить. McNamara длины — Ar вместо Co (оценка).

### #2 — Суперимпозиция (наложение по времени) *(высокий приоритет)*
Dolphin: наложение трассировок разных временных точек — по основанию черепа
(SN/базион-назион), региональные (в/ч по нёбной плоскости, н/ч по симфизу/
каналу), 5-частная по Ricketts; «усреднённая трассировка».
ОРТОС: нет. **План:** сохранить трассировку как временную точку (T1/T2),
зарегистрировать две по выбранному референсу (основание черепа / в/ч / н/ч),
показать наложение + векторы изменений + таблицу Δ. Для детей — отслеживание
роста и результата лечения. Чисто 2D, тянется.

### #3 — Прогноз роста *(высокий приоритет — детская специфика!)*
Dolphin: прогноз роста (Ricketts/Bjork) — проекция ориентиров вперёд по
возрасту.
ОРТОС: нет. **План:** спроецировать ключевые ориентиры на целевой возраст по
средним инкрементам роста (направление/величина по полу), показать «сейчас →
прогноз в N лет» на ТРГ. Прямо в русле детского фокуса ОРТОС.

### #4 — Анализ дыхательных путей *(средний приоритет — хирургия/СОАС)*
Dolphin 3D: объём глоточных дыхательных путей на КЛКТ.
ОРТОС: нет. **План (2D):** на боковой ТРГ — верхние/нижние дыхательные пути
(ширины по McNamara, площадь ретропалатального/ретроглоссального просвета).
Актуально для ортогнатии и СОАС.

### #5 — Протокол операции / клинический отчёт *(средний-высокий)*
Dolphin: Letter System, отчёты, аннотации.
ОРТОС: нет сводного документа. **План:** печатаемый отчёт (HTML→print/PDF):
паспорт пациента, возраст, анализ с нормами, план перемещений (мм/°),
прогноз мягких тканей, тип сплинта, при КДО — протокол активации.

### #6 — Линейка/транспортир + наложение трассировки на фото *(низкий, быстрый)*
Dolphin: Annotation & Measurement; наложение трассировки на фото/снимок.
ОРТОС: нет ad-hoc измерений. **План:** инструмент «линейка» (расстояние мм) и
«угол» на любом снимке; опциональный показ линий трассировки поверх фото.

### #7 — Анализ мягких тканей по Arnett (STCA) *(средний)*
Dolphin шаблоны: soft tissue profile.
ОРТОС: H/V-прогноз есть, именного Arnett-анализа нет. **План:** True Vertical
Line (TVL) анализ Arnett–Bergman — серия мягкотканных измерений для
хирургического планирования.

### Явно вне охвата (пока не планируем)
Aquarium (3D-мультики для пациентов), виртуальный артикулятор, воксельная
3D-суперимпозиция КЛКТ (тяжело для buildless-canvas), биллинг/практис-менеджмент.

## Рекомендованный порядок

1. Библиотека анализов (#1) — максимум клинической ценности на усилие.
2. Суперимпозиция (#2) — ядро цефалометрии, рост/результат.
3. Прогноз роста (#3) — уникальная детская ценность.
4. Анализ дыхательных путей (#4).
5. Протокол операции (#5).
6. Линейка + наложение (#6), Arnett (#7) — полировка.

> Инструмент планирования, не мед. изделие. Методики и нормы — общедоступные,
> проверять клинически.
