# ОРТОС ↔ Dolphin — карта паритета (recon)

Clean-room сравнение: что умеет Dolphin Imaging/Dolphin 3D (по **открытым**
материалам — продуктовые брошюры, независимые исследования) и что из этого
уже есть в ОРТОС. Повторяем функции и клинический поток, без кода/бренда/
контента оригинала; нормы и методики — общедоступные.

Источники (публичные): продуктовый лист Dolphin Imaging 11.95, брошюра 11.5,
независимые работы по суперимпозиции и анализу дыхательных путей (Angle
Orthodontist, JCO, PMC). Ссылки — в сообщении-отчёте.

## Чего нет в ОРТОС (gap-лист, по приоритету)

### #1 — Библиотека анализов ✅ *(реализовано)*
Dolphin: 400+ боковых анализов (Ricketts, McNamara, Steiner, Tweed, Jarabak,
Roth, Sassouni, McLaughlin, Downs, Bjork), фронтальные (Ricketts, Grummons),
настраиваемые; нормы по полу/возрасту/расе.
ОРТОС: **сделано** — переключатель «Анализ» на шаге 5: **ОРТОС (сводный,
детские нормы)** + классические **Steiner, Ricketts, McNamara, Jarabak, Downs,
Tweed, Wits**; каждый = свой список измерений + классические нормы метода.
Data-driven реестр метрик (`CEPH_METRIC`/`CEPH_ANALYSES`); для показателя без
нужной точки — подсказка, что поставить. McNamara длины — Ar вместо Co (оценка).

### #2 — Суперимпозиция (наложение по времени) ✅ *(реализовано)*
Dolphin: наложение трассировок разных временных точек — по основанию черепа
(SN/базион-назион), региональные (в/ч по нёбной плоскости, н/ч по симфизу/
каналу), 5-частная по Ricketts; «усреднённая трассировка».
ОРТОС: **сделано** — вкладка «Наложение» на шаге «Анализ». Снимки-трассировки
(«+ Снимок сейчас», «+ После плана»), регистрация подобием (fitSim) по 2 реперам
выбранного референса: **основание черепа (S–N)**, **в/ч (нёбная ANS–PNS)**,
**н/ч (Go–Me)**. Наложение двух трассировок + оранжевые векторы смещений +
таблица Δ (мм, гор./верт. по FH базовой). Проверено: на осн. черепа план
BSSO даёт в/ч 0, дистальную н/ч +6 мм, Go (проксимальный сегмент) 0 — верно.

### #3 — Прогноз роста ✅ *(реализовано — детская специфика)*
Dolphin: прогноз роста (Ricketts/Bjork) — проекция ориентиров вперёд по
возрасту.
ОРТОС: **сделано** — карточка «🌱 Прогноз роста» во вкладке «Наложение»:
ползунок целевого возраста (текущий → 18) + кнопка «Снимок-прогноз роста».
Проекция ориентиров по средним инкрементам (скорость убывает к 18;
кумулятив — трапеция), направления в FH: н/ч вперёд-вниз (догоняет в/ч),
ветвь вниз-назад (задняя высота растёт быстрее → форвард-ротация), в/ч вперёд,
назион чуть вперёд-вверх; мягкие ткани следуют. Прогноз становится снимком —
накладывается на «сейчас» с таблицей Δ. Проверено (9→16): SNB↑ (81→83.9),
ANB↓ (4.9→3.5), SN-MP↓ (20.1→18.8); подбородок +2.3 вперёд/+5.5 вниз. Ориентир.

### #4 — Анализ дыхательных путей ✅ *(реализовано, 2D)*
Dolphin 3D: объём глоточных дыхательных путей на КЛКТ.
ОРТОС: **сделано** — вкладка «Дых. пути» на шаге «Анализ». Точки на боковой
ТРГ (мягкое нёбо, задняя стенка глотки верх/низ, корень языка) → ширины
**верхних и нижних** дых. путей по McNamara с нормами (~17 / ~11 мм) и флагом
**«⚠ сужение»** (риск обструкции/СОАС). Линии ширины с подписью мм на снимке.
2D-оценка; воздушный столб на DRR слабоват — точнее на обычной плёнке ТРГ.

### #5 — Протокол операции / клинический отчёт ✅ *(реализовано)*
Dolphin: Letter System, отчёты, аннотации.
ОРТОС: **сделано** — кнопка «📄 Протокол» на шаге «План» (ортогнатия и КДО).
Печатаемый отчёт (новое окно → Печать/Сохранить PDF, фолбэк — скачивание HTML):
паспорт пациента (ФИО/пол/ДР/возраст), цефалометрия с возрастными нормами,
фронтальный анализ и дыхательные пути (если размечены), план перемещений (мм/°)
или протокол КДО (аппарат, удлинение, латентность, темп, консолидация), тип
сплинта, дисклеймер. Таблицы с цветовой разметкой нормы.

### #6 — Линейка/транспортир ✅ *(реализовано)*
Dolphin: Annotation & Measurement.
ОРТОС: **сделано** — вкладка «📏 Линейка» на шаге «Анализ». Клик по ТРГ ставит
точки: 2 точки — расстояние (мм при калибровке / px без), 3+ — углы в вершинах
(транспортир). Подписи прямо на снимке, точки перетаскиваются; убрать/очистить.
(Наложение трассировки на фото — профиль уже морфит фото по плану; отдельный
показ линий трассировки на фото пока не делали.)

### #7 — Анализ мягких тканей (в духе Arnett) ✅ *(реализовано)*
Dolphin шаблоны: soft tissue profile.
ОРТОС: **сделано** — анализ «Мягкие ткани (профиль)» в библиотеке (шаг «Анализ»):
носогубный угол, выпуклость без/с носом (G–Sn–Pog′, G–Prn–Pog′), губы к E-линии
Ricketts (верх/низ). Полноценный TVL Arnett (естественное положение головы,
истинная вертикаль) — опционально позже.

### Явно вне охвата (пока не планируем)
Aquarium (3D-мультики для пациентов), виртуальный артикулятор, воксельная
3D-суперимпозиция КЛКТ (тяжело для buildless-canvas), биллинг/практис-менеджмент.
