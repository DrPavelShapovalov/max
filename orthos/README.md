# ОРТОС

Премиальный планировщик **ортогнатической хирургии** — отдельное настольное
приложение (Windows **.exe**, Electron), светлый анимированный интерфейс.
Clean-room аналог ортогнатического планирования Dolphin Imaging (собран по
методу пака replica — повторяет функции и поток, без кода/бренда/контента
оригинала; нормы — общедоступные). **Это отдельная программа, не OSSA.**

## Поток (6 шагов)

1. **Пациент** — ФИО, пол, дата; загрузка данных.
2. **МСКТ → ТРГ** — загружаете серию **МСКТ (DICOM)**, программа строит боковую
   **ТРГ** (проекция-DRR), масштаб берётся из DICOM автоматически. Можно
   загрузить и готовую плёнку ТРГ (фото).
3. **Точки** — для **каждой** цефалометрической точки показывается
   **схема-подсказка** (где её ставить) и описание; точку вы ставите **сами**
   кликом на ТРГ, затем правите перетаскиванием. 17 костных + 7 мягкотканных.
4. **Фото** — загрузка фотографии профиля пациента (документация/сопоставление).
5. **Анализ** — цефалометрия с нормами: SNA, SNB, ANB (+ класс), Wits, SN-MP,
   FMA, U1-NA, L1-NB, межрезцовый, носогубный.
6. **План** — перемещения сегментов (Le Fort I, BSSO, гениопластика) ползунками,
   прогноз мягких тканей, наложение до/после, сводка и анализ «до → после»,
   экспорт PNG. Сохранение/открытие проекта `.orthos`.

## Сборка .exe

CI (`.github/workflows/build-orthos.yml`) собирает Windows-установщик:
Actions → запуск **Build ORTHOS (Windows)** → **Artifacts** → `ORTHOS-Windows-Installer`.
Локально: `npm install && npm run dist` (в папке `orthos/`).

## Технологии

Electron + ванильный JS (без сборщика): `index.html` + `styles.css` + `app.js`
+ `skull.js` (схемы-подсказки). Разбор несжатого DICOM — в приложении.
Сжатый DICOM (JPEG/JPEG2000) — выгрузите несжатую серию.

> Инструмент планирования, не диагностическое мед. изделие. Нормы и прогноз
> мягких тканей ориентировочные — проверяйте клинически.
