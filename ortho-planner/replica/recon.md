# Recon — ОРТО-планнер (аналог Dolphin Imaging, ортогнатический модуль)

Clean-room: воспроизводим **функции и потоки** планирования ортогнатической
операции, не код/логотипы/анализы-бренды/контент Dolphin. Источники — только
публичные (справка, маркетинг, ролики-вокинги, учебники по цефалометрии и STO).

## Step 1 — scope
- **Платформа:** web (одностраничное приложение, работает в браузере, офлайн).
- **Срез (core loop):** от боковой ТРГ → цефалометрия → **хирургическая
  симуляция перемещений челюстей (VTO/STO)** → прогноз мягких тканей → до/после
  → план операции. Это то, ради чего пользуются ортогнатическим модулем.
- **Для кого:** челюстно-лицевой хирург / ортодонт, рус. интерфейс, просто и понятно.

## Step 4 — user flows
```
F01 Планирование операции
    S01 загрузить ТРГ + калибровка -> S02 расставить точки (с подсказками)
    -> S03 посмотреть анализ -> S04 задать перемещения челюстей
    -> S05 прогноз мягких тканей + до/после -> S06 отчёт/экспорт
    edge: снимок не откалиброван; не все точки; экстремальные перемещения
F02 Быстрый пересчёт
    меняю мм в S04 -> S05 и S03 обновляются мгновенно
```
Счётчик кликов happy-path: загрузка → ~15 точек → перемещения → отчёт.

## Step 5 — components
Канвас с точками (drag), список точек с ✓ и подсказкой, слайдеры мм/°,
таблица «значение · норма · статус», переключатель вкладок, оверлей до/после с
прозрачностью, экспорт PNG, панель данных пациента.

## Step 6 — inferred data model
```
Patient   id, name, sex (M|F), dob
Image     src(dataURL), scale_px_per_mm (из калибровки)
Landmark  id, kind(hard|soft), x_px, y_px     (S,N,A,B,Or,Po,ANS,PNS,Go,Gn,Me,
          Pog,Ar,U1t,U1a,L1t,L1a + мягкие Gl,Prn,Sn,Ls,Li,Pog',Me')
Analysis  SNA,SNB,ANB,Wits,SN-MP,FMA,U1-NA(°,mm),L1-NB(°,mm),interincisal,
          nasolabial — вычисляются из Landmark
Plan      maxilla{adv,vert,pitch}, mandible{adv,vert,pitch}, chin{adv,vert}
Predict   смещённые мягкотканные точки по коэффициентам (губы, pog')
          confidence: средняя (коэффициенты усреднённые, зависят от техники)
```

## Step 8 — что НЕ клонируем (skip)
- Фирменные «анализы» и пресеты Dolphin, их база норм, их UI/иконки/копирайт — наши собственные (публичные нормы).
- 3D-КТ модуль, фотоморфинг лица, PACS/база пациентов, интеграции с ОМС/счётами — вне среза (3D уже есть в OSSA).
- Регуляторика (мед. изделие/сертификация) — инструмент планирования, не диагностическое ПО.

## Step 9 — size
Экранов 6, потоков 2, сущностей 5. Трудные места: (1) корректная геометрия
перемещений сегментов и авторотация н/ч, (2) модель прогноза мягких тканей,
(3) калибровка/масштаб. Размер: **M** (ядро — за сессию как v1, дальше итерации).

Core loop · 6 экранов · 2 потока · трудное: перемещения+авторотация, прогноз
мягких тканей, калибровка · вне скопа: 3D/фото/PACS · дальше: /replica-architect.
