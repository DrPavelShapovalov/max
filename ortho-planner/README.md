# ОРТО-планнер

Простой русскоязычный планировщик **ортогнатических операций** — clean-room
аналог ортогнатического модуля Dolphin Imaging (повторяет функции и поток
планирования, без кода/логотипов/контента оригинала; нормы — общедоступные).

Открывается как обычная веб-страница (`index.html`), работает **офлайн в
браузере**, ничего не нужно устанавливать и подключать.

## Что умеет (v1)

**Поток планирования — 6 вкладок:**
1. **Снимок** — загрузить боковую ТРГ (JPG/PNG), откалибровать масштаб по
   известному отрезку (мм), ввести данные пациента.
2. **Точки** — расставить костные и мягкотканные ориентиры с **подсказкой по
   каждой точке** (S, N, A, B, Or, Po, ANS, PNS, Go, Gn, Me, Pog, Ar, резцы
   U1/L1 + профиль G, Prn, Sn, Ls, Li, Pog′, Me′). Точки можно перетаскивать.
3. **Анализ** — цефалометрия с нормами и отметкой норма/выше/ниже: SNA, SNB,
   ANB (+ скелетный класс I/II/III), Wits, SN–MP, FMA, U1–NA (° и мм),
   L1–NB (° и мм), межрезцовый, носогубный угол.
4. **Хирургия (VTO)** — перемещение сегментов ползунками:
   - верхняя челюсть (**Le Fort I**): выдвижение, импакция, наклон (питч);
   - нижняя челюсть (**BSSO**): выдвижение, ротация, авторотация по импакции;
   - подбородок (**гениопластика**): выдвижение, вертикаль.
   На снимке — плановое положение (пунктир) и схема линий остеотомии.
5. **До / После** — прогноз мягких тканей (губы, подбородок по усреднённым
   коэффициентам) и наложение исходного и планового профиля с прозрачностью.
6. **План** — сводка перемещений (мм, °), значения анализа «до → после»,
   экспорт снимка плана в **PNG** и печать.

Сохранение/открытие плана — в файл `.ortho` (кнопки вверху).

## Как пользоваться

1. Открой `index.html` в браузере (двойной клик).
2. Вкладка **Снимок** → «Загрузить боковую ТРГ» → «Отметить отрезок» (кликни 2
   точки известного расстояния, впиши мм) — это даёт масштаб для линейных
   измерений.
3. Вкладка **Точки** → кликай по снимку, точки идут по списку; поправляй
   перетаскиванием.
4. Вкладка **Анализ** → смотри цефалометрию.
5. Вкладка **Хирургия** → двигай ползунки, наблюдай плановый профиль.
6. Вкладка **До/После** и **План** → прогноз, сводка, экспорт.

Колесо мыши — зум, Shift+перетаскивание — панорама.

## Важно

- Это инструмент **планирования**, а не диагностическое мед. изделие. Нормы
  ориентировочные (взрослые), прогноз мягких тканей — по усреднённым
  коэффициентам. Проверяйте клинически.
- Для 3D-планирования по КТ используйте OSSA 3D (соседний модуль репозитория).
